# Quad Draw (Maya style) for Blender

Maya の **Quad Draw** と同じ操作体系でリトポロジーができる Blender アドオンです。
ハイポリ（ライブサーフェス）の上にドットを打ち、Shift で面を張り、Ctrl でエッジループ、
Tab でストリップを伸ばす…という Maya と同じ手の動きで作業できます。

対応バージョン: **Blender 4.2 以降**（Blender 5.0.1 で動作確認済み）

## インストール

1. リポジトリ直下の `quad_draw.zip` をダウンロード
2. Blender → `Edit > Preferences > Add-ons`（Get Extensions）右上の `▼` → **Install from Disk...**
3. `quad_draw.zip` を選択（自動で有効化されます）

## 使い方

### すぐに始める
1. オブジェクトモードでハイポリ（リファレンス）メッシュを選択
2. サイドバー（N キー）→ **Quad Draw** タブ → **New Retopo Mesh**
   - 選択メッシュがライブサーフェスに設定され、空のリトポ用メッシュが作られてツールが起動します

### 既存のメッシュで使う
- 編集モードで `Mesh > Quad Draw`、サイドバーの **Quad Draw** ボタン、または **Shift + Alt + Q**
- ライブサーフェスはパネルの **Live Surface** で指定（空欄なら、表示中の他のメッシュ全部に吸着）

## 操作（Maya Quad Draw と同じ）

| 操作 | 機能 |
|---|---|
| **LMB クリック** | サーフェス上にドットを打つ |
| **LMB ドラッグ**（ドット/頂点/エッジ/面の上） | 移動（サーフェスに吸着したままスライド）。頂点を別の頂点に重ねると自動ウェルド |
| **Shift**（ホバー） | 近くのドット・境界頂点から作られる四角形（三角形）をプレビュー |
| **Shift + LMB クリック** | プレビューした面を作成 |
| **Shift + LMB ドラッグ** | Relax ブラシ（頂点をならしてサーフェスへ再投影） |
| **Ctrl**（ホバー） | エッジループ挿入位置をプレビュー |
| **Ctrl + LMB** | エッジループ挿入（ドラッグで位置をスライドしてから離すと確定） |
| **Ctrl + MMB** | 中央にエッジループを挿入 |
| **Ctrl + Shift + LMB** | ドット／頂点／エッジループ／面を削除（ドラッグで連続削除） |
| **Tab + LMB ドラッグ**（境界エッジ上） | 境界エッジからクアッドを押し出し、ドラッグし続けると連続したストリップになる（クリックだけなら1枚押し出し） |
| **Tab + LMB ドラッグ**（何もない面上） | 新しいクアッドストリップを描画 |
| **B + ドラッグ（左右）** | ブラシ／ストリップのサイズ変更 |
| **Ctrl + Z / Ctrl + Shift + Z** | アンドゥ／リドゥ（ドットも含めて戻ります） |
| **Esc / Enter / Q** | ツール終了 |

中ボタン・ホイール・テンキー・Alt+マウス（Maya 風ナビゲーション）はそのままビュー操作に使えます。
ツール起動中もサイドバーの設定は変更できます。

## 設定（サイドバー > Quad Draw）

- **Live Surface** — 吸着先のメッシュ
- **Symmetry (X)** — リトポオブジェクトのローカル X 軸でミラー。ドット・面張り・ループ挿入・移動・Relax・削除・押し出し全てがミラーされ、中央付近の頂点は X=0 にスナップ
- **Relax Brush / Relax Strength / Relax Border** — Relax ブラシの半径・強さ・境界頂点を境界に沿って動かすか
- **Strip Width** — Tab ドラッグで描くストリップの幅（ピクセル）
- **Pick Radius** — コンポーネントを拾う／自動ウェルドする距離（ピクセル）
- **Auto Weld** — 近くの頂点へ自動で結合
- **Retopology Overlay** — 起動時にビューポートの Retopology オーバーレイを ON（リトポメッシュが常にハイポリの手前に見える）
- **Clear Dots** — 残っているドットを全て消去

## メモ

- ドットは Maya と同じくメッシュとは別に保持され、ツールを閉じても次回起動時に残ります。
- 作成した面の向きは隣接面・サーフェス法線に合わせて自動で揃えます。
- 裏側（サーフェスに隠れた）頂点やエッジは拾いません。
