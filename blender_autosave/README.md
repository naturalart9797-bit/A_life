# Auto Save Pro（Blender 自動保存アドオン）

一定間隔で .blend を自動保存し、タイムスタンプ付きバックアップを世代管理するアドオンです。
Blender 2.93 〜 4.x / 5.x 対応（4.2 以降は Extension としてもインストール可能）。

## 機能
- 指定した間隔（分）で自動保存。変更があるときだけ保存するオプション付き
- 保存方法を選択
  - **バックアップ**: `名前_autosave_YYYYMMDD_HHMMSS.blend` として別ファイルに保存（作業ファイルはそのまま）
  - **上書き保存**: 作業中の .blend を上書き
  - **両方**
- バックアップ保持数を超えた古いファイルは自動削除
- 一度も保存していないファイル（Untitled）も `~/Blender_AutoSave` に保存
- レンダリング中や、移動・回転などの操作中は保存を数秒延期
- 3D ビューのサイドバー（N キー）→ **AutoSave** タブ
  - 最終保存時刻 / 次回保存までの時間
  - 今すぐ保存・保存先フォルダを開く・最新バックアップを開く

## インストール
1. `blender_autosave.zip` をダウンロード
2. Blender: **編集 > プリファレンス > アドオン**（4.2 以降は右上 ▼ → **ディスクからインストール**）
3. zip を選択して有効化

## 保存先
- 空欄（デフォルト）: .blend と同じ場所の `autosave/` フォルダ
- 任意のフォルダも指定可（`//` で始まる相対パスも可）
