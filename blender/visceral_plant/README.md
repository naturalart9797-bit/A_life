# Visceral Plant（内臓植物ジェネレーター）— Blender アドオン

茎や根が **胃や腸のような構造** になっている、奇妙な植物のメッシュを手続き的に生成します。

## 主な特徴

| 部位 | 内臓のモチーフ | 内容 |
| --- | --- | --- |
| 茎・枝 | 大腸（結腸） | 環状のくびれ（ハウストラ）と、縦の溝（結腸ヒモ）を持つ蛇行したチューブ |
| 茎の途中 | 胃 | J 字に曲がりながら袋状に膨らみ、幽門のような括約部でくびれる |
| 根 | 小腸 | 折り返しを繰り返しながら下へ伸び、側根に分岐 |
| 地際 | 胃底 | 茎の根元の球根状の膨らみ |
| 枝先 | 袋 | 胃袋のような実 |

- ノイズ場による蛇行と、反転する回転軸による「腸の折り畳み」
- 空間ハッシュによる自己回避（チューブ同士のめり込みを抑える）
- ボクセルリメッシュで分岐部をなめらかに融合
- 血管模様・サブサーフェス・コートで濡れた肉質を表現するマテリアル

## インストール

### Blender 4.2 以降
1. `visceral_plant` フォルダを zip に圧縮します（zip の中に `visceral_plant/__init__.py` が入る形）。
2. `編集 > プリファレンス > アドオン` 右上の `∨` メニュー → **ディスクからインストール** で zip を選択。

### Blender 3.6 〜 4.1
1. 同様に zip にして、`プリファレンス > アドオン > インストール` から選択。
2. 「Visceral Plant」にチェックを入れて有効化。

## 使い方

- 3D ビューポートで `Shift + A` → **メッシュ > Visceral Plant (内臓植物)**
- またはサイドバー（`N` キー）の **Visceral** タブ → 「内臓植物を追加」

追加直後に左下に出る「調整パネル」で、シードや各パラメーターを変更すると即座に再生成されます。

### おもなパラメーター

- **シード**: 形のバリエーション
- **茎**: 長さ・太さ・先細り・蛇行・巻き（腸の折り畳み）・折り返し頻度・上向きの力
- **腸の表面**: くびれの深さ／間隔、縦溝の数／深さ、表面のゆらぎ
- **胃袋・実**: 茎の胃袋の数と大きさ、枝に胃袋が付く確率、地際の膨らみ、枝先の実
- **枝**: 数・階層・長さ・太さ比
- **根**: 数・長さ・太さ・広がり・蛇行・巻き（小腸）・折り返し頻度・下向きの力・側根
- **メッシュ**: 断面の分割数、自己回避、融合（リメッシュ）とその細かさ、スムーズ、サブディビジョン、モディファイア適用
- **マテリアル**: 肉の色 2 色と血管の色

### ヒント

- 動作が重いときは「融合の細かさ」を大きくするか、「融合」をオフにしてください。
- 腸らしさを強めたいときは「巻き」「折り返し頻度」「くびれの深さ」を上げます。
- 植物寄りにしたいときは色を緑系に、「胃袋の数」を減らし「上向きの力」を上げます。
- 融合をオフにすると、ハウストラや縦溝のディテールがよりくっきり残ります。
