# Visceral Plant（内臓植物ジェネレーター）— Blender アドオン

茎や根が **胃や腸のような構造** になっている、奇妙な植物のメッシュを手続き的に生成します。

## 主な特徴

| 部位 | 内容 |
| --- | --- |
| 幹 | 腸のような管が何本もねじれ合いながら垂直に伸びる。ループやこぶ、環状のくびれ（ハウストラ）付き |
| 胃袋 | 幹の途中で、管の束に抱え込まれた J 字の袋状の塊 |
| 根 | 束の下端で管がほどけ、弧を描いて地面に降り、地面を這って先端がくるりと巻く |
| 上部 | 一本の細い茎にまとまり、先端のふくらみと小枝が付く |

## インストール

### Blender 4.2 以降
1. `visceral_plant` フォルダを zip に圧縮します（zip の中に `visceral_plant/__init__.py` が入る形）。
2. `編集 > プリファレンス > アドオン` 右上の `∨` メニュー → **ディスクからインストール** で zip を選択。

### Blender 3.6 〜 4.1
1. 同様に zip にして、`プリファレンス > アドオン > インストール` から選択。
2. 「Visceral Plant」にチェックを入れて有効化。

## 使い方

1. サイドバー（`N` キー）の **Visceral** タブ →「内臓植物を追加」（`Shift + A` → メッシュ → Visceral Plant でも可）
2. 植物を選択した状態でパネルの値を変えると、その場で作り直されます（「自動更新」）。
3. 形が決まったら「確定」でモディファイアを適用し、通常のメッシュにします。

パネル: 幹（腸の束）／胃袋／上部の茎／根／腸の表面／メッシュ／マテリアル

### ヒント

- 動作が重いときは「融合の細かさ」を大きくするか、「融合」をオフにしてください。
- 腸らしさを強めたいときは「巻き」「折り返し頻度」「くびれの深さ」を上げます。
- 植物寄りにしたいときは色を緑系に、「胃袋の数」を減らし「上向きの力」を上げます。
- 融合をオフにすると、ハウストラや縦溝のディテールがよりくっきり残ります。
