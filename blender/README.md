# Plant Spear Generator (Blender アドオン)

蔓・苞葉・巻きひげ・小葉・トゲでできた「植物性の槍」を、パラメータを動かしながら生成する Blender アドオンです。

![presets](plant_spear_presets.png)

左から `Twisted`（デフォルト）/ `Pole + Vines` / `Tight Braid` / `Thorny` / `Lush` / `Minimal` / `Wild`

## 本体のタイプ（Body）

- **Twisted**（デフォルト）: 支柱なし。茎や葉（ストランド）をねじり合わせたものがそのまま槍の本体になります。縛りの位置できつくねじれ、上の方では束がほどけて広がり、穂先の根元を包みます。何本かは途中で束から抜け出してくるっと巻きます。
- **Pole**: 芯となる柄に蔓が巻きつくタイプ。

## インストール

1. Blender で **Edit > Preferences > Add-ons**
2. 右上の **▼ > Install from Disk...** で `plant_spear.py` を選択し、有効化
   - インストールせずに試すなら、Text Editor で `plant_spear.py` を開いて **Run Script** でもOK

Blender 3.6 / 4.x / 5.0 で動作します（5.0.1 で確認済み）。

## 使い方

- 3D ビューで **N** キー → **Plant Spear** タブ → **Add Plant Spear** からプリセットを選ぶ
  （**Add > Mesh > Plant Spear** からも追加できます）
- 槍を選択したままパネルのスライダーを動かすと、**その場で再生成**されます
- **Seed** の横のボタンを押すと、同じパラメータで別の個体になります
- **Duplicate as Variant**: 別シードの複製を横に並べて見比べられます
- **Apply Preset**: プリセットに戻します（シードはそのまま）
- 重いときは **Live Update** をオフ → **Regenerate** ボタンで手動更新、または **Detail** を下げてください
- 形が決まったら **Convert to Plain Mesh** で通常メッシュにでき、手作業でスカルプトや編集をできるようになります

## パラメータ一覧

| セクション | 主なパラメータ |
|---|---|
| 全体 | Body（Twisted / Pole）, Seed, Length（全長）, Detail（ポリゴン量）, Subdivision, Smooth Shading |
| Twisted Body（ねじり本体） | 本数、ねじり回数、縛り位置での締まり、詰まり具合、**平たさ（丸い茎↔平たい葉）**、ゆるみ、ほどけて広がる量・位置・範囲、束から抜け出す確率・範囲・長さ・巻き数、穂先をどこまで包むか |
| Shaft / Bundle（柄・束の形） | 半径（Twisted では束全体の太さ）・テーパー、反り（量・方向）、うねり、表面の筋、石突きの長さ・鋭さ |
| Head（穂先） | 長さ・幅・最大幅の位置・先端の鋭さ、結晶状の面（数・角張り・ねじれ）、中肋 |
| Sheath Leaves（苞葉） | 枚数・長さ・付け根位置・幅・先端の開き・ねじれ・ばらつき |
| Extra Vines（追加の蔓） | 本数・範囲・巻き数・逆回りの割合、太さ・**平たさ（丸い蔓↔リボン状の葉）**・リボンのねじれ、ゆるみ・ループ状の膨らみ、先端の渦巻き |
| Binding Wrap（縛り） | 位置・長さ・巻き数・太さ・交差巻き |
| Tendrils（巻きひげ） | 本数・生える範囲・長さ・巻き数・巻きの締まり・角度・太さ |
| Leaves（小葉） | 枚数・大きさ・幅・角度・反り・蔓上の生える範囲 |
| Thorns（トゲ） | 数・大きさ・角度・蔓/柄のどちらに生やすか |
| Colors（色） | 柄/穂先/蔓/葉 それぞれの暗色・明色（ノイズで混ぜた自動マテリアル） |

## 補足

- 1つのメッシュに 4 つのマテリアルスロット（Shaft / Head / Vine / Leaf）が割り当てられているので、マテリアルを差し替えれば質感を自由に変更できます。
- UV は自動生成されています（チューブは周方向×長さ方向）。
- 単位はメートル。デフォルトの全長は 1.8 m です。
