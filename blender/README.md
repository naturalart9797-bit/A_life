# 茨の森ジェネレーター (Blender アドオン)

![preview](preview.jpg)

`thorn_forest.py` は Blender 上で「茨の森」を手続き生成するアドオンです。
1 ファイルで完結しており、外部依存はありません (Blender 3.6 以降 / 5.2 で動作確認)。

生成されるもの:

| オブジェクト | 内容 |
| --- | --- |
| `TF_Vines` | 蔓 (カーブ)。何本もの蔓がねじれ合った幹、幹の先からアーチを描いて垂れる樹冠、枝、地面から弧を描く藪 |
| `TF_Thorns` | 蔓の太さに比例した、根元側へ鉤状に反ったトゲ |
| `TF_Leaves` | 細い蔓に付く小さな葉 |
| `TF_Roses` | 細い蔓の先に咲く薔薇 |
| `TF_Ground` / `TF_Fog` / `TF_Moon` | 地面・地表に溜まる高さ霧・月光 (「雰囲気」オプション) |

すべて `Thorn Forest` コレクションに入り、再生成時は前回分が置き換わります。
同じシードなら毎回同じ森になります。

## 使い方

### ドラッグ&ドロップでインストール (Blender 4.2 以降)

1. `thorn_forest-1.0.0.zip` を Blender のウィンドウにドラッグ&ドロップし、確認ダイアログで「OK」
2. 3D ビューで `N` キー → サイドバーの「茨の森」タブ

(編集 > プリファレンス > アドオン > 右上の ▼ > ディスクからインストール で zip を選んでも同じです。
Blender 3.6〜4.1 では zip ではなく `thorn_forest.py` を同じメニューから選んでください。)

zip は `python3 build_zip.py` で `thorn_forest.py` と `blender_manifest.toml` から作り直せます。
3. パラメータを調整して **茨の森を生成**。**シードを変えて再生成** で別のバリエーション

### スクリプトとして

テキストエディタで `thorn_forest.py` を開いて「スクリプト実行」するとパネルが登録されます。

### ヘッドレス (コマンドライン)

```sh
# 生成して .blend に保存
blender -b -P thorn_forest.py -- --seed 7 --tree-count 12 --save forest.blend

# カメラを置いて Cycles でレンダリング
blender -b -P thorn_forest.py -- --seed 3 --render forest.png --samples 64

# 全オプション
blender -b -P thorn_forest.py -- --help
```

Python コンソールからは `build_forest(seed=3, tree_count=12)` のように呼べます
(パネルの各項目名がそのまま引数名です)。

## 主なパラメータ

- **茨の木**: 本数・幹の高さ・幹を構成する蔓の本数・ねじれ(巻き数)・樹冠の蔓の長さ
- **枝・藪**: 枝分かれの階層と数、藪の株数、うねり (ノイズ場による曲がり)、垂れ下がり (先端ほど強い重力)
- **トゲ**: 1 m あたりの数・長さ・反り (マイナスで先端側へ反る)
- **葉・薔薇**: 有無・密度・大きさ・数
- **シーン**: 地面・霧と月光・メッシュ変換 (FBX/OBJ 等への書き出し用)

## 重さの目安

デフォルト設定で蔓 約1000本、トゲ 約30万頂点。重い場合は
「解像度」を大きく、「トゲ密度」「枝の階層」「藪の数」を小さくしてください。
カーブのままにしておくと、生成後でもカーブのプロパティ (ベベルの解像度など) で軽さを調整できます。
