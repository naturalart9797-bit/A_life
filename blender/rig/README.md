# flower_v008 リグ

`flower_v008_rig.blend` は、`flower_v008.blend` に `rig_flower_fairy.py` を実行して作ったファイルです。

## 変更したもの（これ以外は元ファイルのまま）
- `fairy_geo`：ウェイトと Armature モディファイア（Subdivision の前）を追加
- `eye_L_geo` / `eye_R_geo`：`fairy_rig` の `head` にペアレント
- `fairy_grp` コレクションに `fairy_rig` と `fairy_tail_curve`（レンダーされない）を追加
- コントローラーの形状用メッシュを `fairy_rig_widgets` コレクションに追加（ビューレイヤーから除外済みなので、表示もレンダーもされない）
- `stomach_geo` と茎にシェイプキーを追加（値 0 なら元と同じ形）
- 元ファイルで未使用だったデータ（`bug_*` の画像、`VineGrow_*` のマテリアル）は、保存時に消えないようフェイクユーザーを付けました
- `fairy_wrap_path`（巻き付け用パス、レンダーされない）とテキスト `fairy_wrap.py`（巻き付けツール）を追加
- 画像の相対パス（`//../../texture/…`）は元のままです。このファイルは元ファイルと同じフォルダに置いてください

花・茎・花びら・口・既存の `Armature`・カメラ・シーン設定には触っていません。

## 妖精 fairy_rig（ポーズモードで操作）
| 色 | コントローラー | 操作 |
|---|---|---|
| 黄 | `root`（口の底の穴の大きな輪） | 妖精全体を移動・回転 |
| 緑 | `tail_base`, `tail_ctrl.01`〜`12` | 蛇の部分。G で動かすと胴がなめらかにくねる。R で回すとカーブの向き、S でカーブの張りが変わる |
| 黄 | `torso`（腰の大きい輪） | 蛇部分のカーブの上端。回すと上半身の向きが変わる |
| 黄 | `hips` `spine` `spine.001` `chest` `neck` `head` | 体幹の FK（R で回す） |
| 青/赤 | `shoulder` `upper_arm` `forearm` `hand`（.L 青 / .R 赤） | 腕の FK |
| 橙 | `hand_ik.L/R`（手の箱）, `arm_pole.L/R`（肘の後ろの球） | 腕の IK。箱を動かすと手が付いてくる。球で肘の向きを決める |
| 青/赤 | `thumb` `index` `middle` `ring` `pinky` `.01〜.03` | 指の FK |

- **IK / FK の切り替え**：`hand_ik.L`（または `.R`）を選び、N パネル →「アイテム」→「プロパティ」の `IK_FK` を変えます。1 = IK（初期値）、0 = FK です。
- **蛇部分の仕組み**：`DEF-tail.001`〜`040`（40本、非表示）が、コントローラーで曲げたカーブに Spline IK で沿います。
- **伸び縮みしない**：蛇部分の長さは固定です。上半身（`hips`）は常に蛇部分の先端に乗っています。カーブを体の長さより長く引き伸ばすと、届かない分の上側の輪は効きません。
- `hand_ik` / `arm_pole` は `hips` についていきます。
- **骨コレクション**：Root / Tail / Torso / Body / Arms / Arm IK / Fingers / Deform（Deform は非表示）

## 巻き付け（蛇部分を脚などに巻き付ける）
蛇部分には 2 つのモードがあり、`root` のプロパティ `tail_mode`（N パネル → アイテム → プロパティ）で切り替えます。
- `tail_mode = 0`：緑の輪（`tail_ctrl`）で自由にくねらせる
- `tail_mode = 1`：巻き付け用パス `fairy_wrap_path` に沿わせる
- 0〜1 の途中の値にキーを打てば、くねっている状態から巻き付いた状態へなめらかに移行できます。

### 手順
1. 巻き付けたい相手と同じシーンに妖精を置く（Append / Link）
2. 相手の Armature をポーズモードにして、巻き付けたい脚のボーンをクリックする（オブジェクトならオブジェクトモードで選択）
3. テキストエディタで `fairy_wrap.py` を開き、先頭の数値を調整して ▶（Alt+P）で実行する
   - `RADIUS`：脚の中心から蛇の中心までの距離（脚の半径 + 0.06）
   - `TURNS`：巻く回数
   - `PITCH`：1 周で進む距離（0.12 以上で蛇どうしが重ならない）
   - `START`：巻き始めの位置（ボーンの根元 0 〜 先 1）
   - `DIRECTION`：巻く向き（1 / -1）
   - `EXIT`：巻き終わってから上半身までの長さ
4. `fairy_wrap_path` が脚のまわりに螺旋で作られ、そのボーンにペアレントされます（脚が動いても巻き付いたまま）。`tail_mode` は自動で 1 になります。
5. 微調整は `fairy_wrap_path` を編集モードで直接いじります（最初の 2 点は穴にフックされているので動かさない）。上半身の向きは `hips` / `spine` / `chest` を回して調整します。

### 知っておくこと
- 蛇部分は伸び縮みしないので、上半身は「穴から体の長さ（3.02）だけパスを進んだ位置」に来ます。上半身を高くしたいときは `TURNS` を減らすか `PITCH` を大きくし、低くしたいときはその逆にします。
- 緑の輪は `tail_mode = 0` のときだけ効きます。

## 胃袋（ボーンなし・シェイプキー）
`stomach_geo` を選び、プロパティ →「オブジェクトデータ」→「シェイプキー」で操作します。
- `膨張`：0〜2（1 で 15% 膨らむ）
- `収縮`：0〜2（1 で 15% 縮む）

値の横の ◇ を押すとキーが打てます。胃袋に絡む蔓の `胃袋_膨張` / `胃袋_収縮` は、このスライダーに自動で連動します。
