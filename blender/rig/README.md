# flower_v008 リグ

`flower_v008_rig.blend` は、`flower_v008.blend` に `rig_flower_fairy.py` を実行して作ったファイルです。

## 変更したもの（これ以外は元ファイルのまま）
- `fairy_geo`：ウェイトと Armature モディファイア（Subdivision の前）を追加
- `eye_L_geo` / `eye_R_geo`：`fairy_rig` の `head` にペアレント
- `fairy_grp` コレクションに `fairy_rig` と `fairy_tail_curve`（レンダーされない）を追加
- コントローラーの形状用メッシュを `fairy_rig_widgets` コレクションに追加（ビューレイヤーから除外済みなので、表示もレンダーもされない）
- `stomach_geo` と茎にシェイプキーを追加（値 0 なら元と同じ形）
- 元ファイルで未使用だったデータ（`bug_*` の画像、`VineGrow_*` のマテリアル）は、保存時に消えないようフェイクユーザーを付けました
- 画像の相対パス（`//../../texture/…`）は元のままです。このファイルは元ファイルと同じフォルダに置いてください

花・茎・花びら・口・既存の `Armature`・カメラ・シーン設定には触っていません。

## 妖精 fairy_rig（ポーズモードで操作）
| 色 | コントローラー | 操作 |
|---|---|---|
| 黄 | `root`（口の底の穴の大きな輪） | 妖精全体を移動・回転 |
| 緑 | `tail_base`, `tail_ctrl.01`〜`18` | 蛇部分。**G（移動）だけ**で形を作る（回転・スケールはロック済み） |
| 黄 | `torso`（腰の大きい輪） | 上半身全体の移動・回転。尾のコントローラーとは独立 |
| 黄 | `hips` `spine` `spine.001` `chest` `neck` `head` | 体幹の FK（R で回す） |
| 青/赤 | `shoulder` `upper_arm` `forearm` `hand`（.L 青 / .R 赤） | 腕の FK |
| 橙 | `hand_ik.L/R`（手の箱）, `arm_pole.L/R`（肘の後ろの球） | 腕の IK |
| 青/赤 | `thumb` `index` `middle` `ring` `pinky` `.01〜.03` | 指の FK |

- **IK / FK の切り替え**：`hand_ik.L`（または `.R`）を選び、N パネル →「アイテム」→「プロパティ」の `IK_FK` を変えます（1 = IK、0 = FK）。
- **蛇部分の仕組み**：緑の輪 19 個と `torso` が NURBS カーブの制御点になっています。`DEF-tail.001`〜`040`（40本、非表示）が、そのカーブに Spline IK で沿います。NURBS なので、輪をどう動かしても曲線は常になめらかです。
- **上半身は尾と独立**：上半身は `torso` にぶら下がっているので、緑の輪を動かしても上半身は動きません。
- **ねじれ補正**：Spline IK は、カーブが曲がるたびに骨のねじれが少しずつずれていきます。そのずれ（尾の先と `torso` の差）を、尾全体に根元 0% → 先端 100% で分配して打ち消しています。輪で大きくループさせても、腰の下がすぼまりません。
- **つなぎ目**：カーブの両端は 2 点ずつ固定です（穴ではまっすぐ立ち上がり、上半身には `torso` の向きのまままっすぐ入ります）。上半身をどう傾けても、尾とのつなぎ目は折れません。ウェイトも腰の下でなめらかにブレンドしています。
- **尾の長さ `tail_length_lock`**（`torso` を選び、N パネル → アイテム → プロパティ）
  - **0（初期値）**：上半身は `torso` の位置に固定。尾は穴から上半身までを結ぶので、輪の置き方によって長さが変わる。長さを変えたくないときは、輪をカーブ全体の長さが変わらないように並べる
  - **1**：尾の長さは固定（3.02）。上半身の位置は尾の先に来て、向きは `torso` のまま
  - 「上半身を固定する」と「尾の長さを固定する」は同時にはできないので、このスイッチで選びます。途中の値にキーを打って切り替えることもできます

## 巻き付けのやり方（一般的な Spline IK リグの使い方）
1. 緑の輪を G で動かして、相手の脚のまわりに螺旋状に並べる
   - 目安は 1 周に 6〜8 個
   - 輪と脚の中心の距離は「脚の半径 + 0.06（蛇の太さの半分）」
   - 1 周ごとに 0.12 以上ずらすと、蛇どうしが重ならない
2. 脚が動くシーンでは、**脚に巻いている輪だけ**に Child Of コンストレイントを付ける
   - ボーンプロパティ → コンストレイントを追加 → Child Of
   - ターゲット：相手の Armature、ボーン：脚のボーン
   - 「逆行列を設定（Set Inverse）」を押す
   - これで、その輪は脚と一緒に動き、蛇は巻き付いたままになります。
   - 途中で巻き付く・離れるときは、Child Of の「影響」にキーを打って切り替えます（切り替えるフレームで Set Inverse し直す）。
3. 穴の近くの輪と、上半身側の輪は Child Of を付けずに自由に動かす
4. 上半身の位置と向きは `torso` で決め、`hips` / `spine` / `chest` で調整する

## ウェイトの調整
`fairy_geo` のウェイトをウェイトペイントで直せば、そのまま反映されます。
- ウェイトは `fairy_geo` の頂点グループ（ボーンと同じ名前）に入っていて、リグはそれをそのまま使います。
- 蛇部分のウェイトは `DEF-tail_base` / `DEF-tail.001〜040` です（腰の下の約 0.3 の範囲は `hips` とブレンド）。塗るときは、アーマチュアのボーンコレクション `Deform` を表示してください（普段は非表示）。体・腕・指はボーン名と同じです。
- 頂点グループの名前を変えたり消したりしないでください。
- `rig_flower_fairy.py` を再実行するとウェイトが上書きされます。ウェイトを直したら、スクリプトは再実行しないでください。

## 胃袋（ボーンなし・シェイプキー）
`stomach_geo` を選び、プロパティ →「オブジェクトデータ」→「シェイプキー」で操作します。
- `膨張`：0〜2（1 で 15% 膨らむ）
- `収縮`：0〜2（1 で 15% 縮む）

値の横の ◇ を押すとキーが打てます。胃袋に絡む蔓の `胃袋_膨張` / `胃袋_収縮` は、このスライダーに自動で連動します。
