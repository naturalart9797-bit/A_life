# Water Flower — 成長する花 (Blender, 試作)

花びらを数式で描くのではなく、植物の花びらと同じ仕組み（脈・成長・力学）から形を計算して作るアドオンです。
いまはスイセンの **外花被片** と **副花冠（中央のラッパ）** を作る試作段階です。

左: 参考画像 / 中・右: このアドオンで作ったもの

![growth](preview_growth.png)

## しくみ
1. **原基**: 成長前の平らな花びら。単子葉植物なので脈は平行で、付け根と先端で集まる
2. **二層の膜**: 表（向軸側）と裏（背軸側）の表皮を、厚みの分だけ離した 2 枚の膜にしてつなぐ
3. **成長**: 場所・方向・層ごとの伸び率を決める
   - 縁が中央より伸びる → 余りが座屈してフリルになる（副花冠の縁）
   - 脈は伸びにくく硬い
   - 表と裏の伸びの差 → 反り・くぼみ・中央の折れ
4. **力学**: 成長後の長さを満たそうとする膜のエネルギーを最小にして、釣り合いの形を求める（粗い格子から細かい格子へ）

## 使い方
1. `water_flower.zip` をインストール（4.2 以降は `エクステンション` → `ディスクからインストール`）
2. `N` → **WaterFlower** タブ →「スイセンを成長させる (試作)」
   - 下書き: 約 1 分 / 細かい: 数分（その間 Blender は止まって見えます）

## まだできていないこと
- 花びらの付け根を花筒に付ける・内花被片・しべ・子房
- 水をためる（副花冠の底を花筒で閉じる）
- 成長で開くアニメーション
- 副花冠の縦ひだ・細かいフリル、花びらのねじれ、部品どうしの接触
- 計算の高速化
