# Auto Retopo（顔・手の自動リトポ）for Blender

スキャンやスカルプトの上にガイド点を打つと、アニメーション向けのトポロジーを自動で作るアドオンです。
- **顔**: リアルな顔向け。目・口の周りの同心ループ、**鼻の穴と小鼻（鼻翼）を囲むループ**、ほうれい線の流れを持つ顔マスク
- **手**: 12分割の指。関節ごとにループを密に入れ、甲側に**楕円の関節ループ**を入れる。手のひら・水かき・親指・前腕も作る

できたメッシュは Quad Draw アドオンでそのまま手直しできます。

対応バージョン: **Blender 4.2 以降**（Blender 5.0.1 で動作確認）

## インストール

`auto_retopo.zip` を `Edit > Preferences > Add-ons > ▼ > Install from Disk...` で選択します。

## 使い方

1. オブジェクトモードで、スキャン／スカルプトのメッシュを選択する
2. サイドバー（N キー）→ **Auto Retopo** タブで **Face** か **Hand** を選ぶ
3. **Place Guides** を押し、画面左下に出る名前の場所を順番にクリックする
   - 置いた点はドラッグで動かせる
   - `←` `→` で置き直したいガイドを選び、クリックで置き直す
   - `Backspace`（または `Ctrl+Z`）で1つ戻す
   - `Enter` で確定、`Esc` で取り消し
   - 中ボタン・ホイール・テンキーでビュー操作できる
   - 配置中はパネルのボタンが「配置中…」になります（二重に起動しません）
4. 全部置いたら **Generate Retopology** を押す → `<名前>_retopo_face` / `_hand` が作られる

ガイドはスキャンのオブジェクトに保存されます。置き直して何度でも生成し直せます。

## 顔のガイド（シンメトリー時 17 点）

| 中心線 | 片側（反対側は自動でミラー） |
|---|---|
| おでこの上（マスク上端の中央） | 目頭 |
| 眉間 | 目尻 |
| 鼻の先 | 上まぶたの中央 |
| 鼻の下（鼻と上唇の境目） | 下まぶたの中央 |
| 上唇の合わせ目の中央 | 口角 |
| 下唇の合わせ目の中央 | こめかみ（目の高さのマスク端） |
| あご先（マスク下端の中央） | エラ（口の高さのマスク端） |
| | おでこの上の端（マスク上端の角） |
| | 小鼻のわき（小鼻の付け根の外側） |
| | 鼻の穴の外側の端 |

- 作られるのは顔の**マスク**です。どこまで含めるかは「マスク上端」「こめかみ」「エラ」「あご先」のガイドで決まります。目・口・鼻の穴は穴になります。
- **Symmetric**: 中心線の点から左右の鏡面を求め、片側のガイドをミラーして結果も左右対称にします。顔が左右非対称なスキャンでは OFF にして、両側（計27点）を打ってください。
- **Density**: 1 = 約280頂点、2 = 約950頂点（初期値）、3 = 約2000頂点

## 手のガイド（21 点・すべて手の甲側）

1. 手首（手の甲側の中央）
2. 親指 → 人差し指 → 中指 → 薬指 → 小指 の順に、各指 4 点
   - 付け根の関節（ナックル）→ 第2関節 → 第1関節 → 指先
   - 親指は「付け根（手首寄りの膨らみ）→ 付け根の関節 → 関節 → 指先」

- **Finger Edges**: 指1本の周りの分割数。12（初期値・約1200頂点）または 8（軽量・約770頂点）
- **Knuckle Loops**: 各関節（ナックル・第2関節・第1関節、親指の関節）の甲側に楕円のループを入れる
- **Forearm Loops**: 手首より先の前腕に伸ばすループ数（スキャンに前腕がある範囲だけ作られる）

指を曲げたポーズでも、関節の位置に沿ってチューブが曲がります。頂点は骨の中心から外向きにレイを飛ばして置くので、指同士がくっついていても隣の指に吸着しにくい作りです。

## 仕組み

- **顔**: 理想的な顔トポロジーを「四角形パッチのレイアウト」としてコードで設計し、そこから型を生成します。ガイド点で位置合わせ（相似変換）と RBF 変形を行い、型の相対形状を保ったまま表面への吸着と緩和を繰り返します。
- **手**: ガイドから骨格（各関節の骨の中心と太さ）を推定し、その周りに輪を作って表面に投影します。

## 制限

- 全身にはまだ対応していません（顔マスクと手のみ）。
- 動作確認は合成した頭部・手のモデルで行っています。実際のスキャンでは、ガイドの位置で結果が変わります。気になる所は Quad Draw で整えてください。
