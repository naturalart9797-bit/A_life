# Auto Retopo（顔・手の自動リトポ）for Blender

スキャンやスカルプトの上にガイド点を打つと、アニメーション向けのトポロジーを自動で作るアドオンです。
- **顔／頭部**: リアルな顔向け。目・口の周りの同心ループ、**鼻の穴と小鼻（鼻翼）を囲む二重ループ**、ほうれい線の流れ、あごの下。**頭全体（頭頂・後頭部・耳の付け根・首）**まで作れる
- **手**: 12分割の指を密な輪切りで作り、甲側に**楕円の関節ループ**を入れる。母指球から伸びる親指、手のひら、水かき、前腕も作る

できたメッシュは Quad Draw アドオンでそのまま手直しできます。

対応バージョン: **Blender 4.2 以降**（Blender 5.0.1 で動作確認）

## インストール

`auto_retopo.zip` を `Edit > Preferences > Add-ons > ▼ > Install from Disk...` で選択します。

## 使い方

1. オブジェクトモードで、スキャン／スカルプトのメッシュを選択する
2. サイドバー（N キー）→ **Auto Retopo** タブで **Face** か **Hand** を選ぶ
3. **Place Guides** を押し、画面左下に出る名前の場所を順番にクリックする
   - 置いた点はドラッグで動かせる
   - `←` `→` で置き直したいガイドを選び、クリックで置き直す
   - `Backspace`（または `Ctrl+Z`）で1つ戻す
   - `Enter` で確定、`Esc` で取り消し
   - 中ボタン・ホイール・テンキーでビュー操作できる
   - 配置中はパネルのボタンが「配置中…」になります（二重に起動しません）
4. 全部置いたら **Generate Retopology** を押す → `<名前>_retopo_face` / `_hand` が作られる

ガイドはスキャンのオブジェクトに保存されます。置き直して何度でも生成し直せます。

## 顔のガイド（シンメトリー時 21 点、頭全体は +8 点で 29 点）

配置中は画面右下に**顔の図**が出て、次に打つ点が赤で表示されます。

| 中心線（8点） | 片側（13点・反対側は自動でミラー） |
|---|---|
| おでこの上（マスク上端の中央） | 目頭 |
| 眉間（左右の眉頭の間） | 目尻 |
| 鼻の先（一番前に出た所） | 上まぶたの縁の中央 |
| 鼻の下（鼻柱と上唇の境目） | 下まぶたの縁の中央 |
| 唇の合わせ目の中央（上唇側） | 鼻の穴の内側の端（鼻柱側） |
| 唇の合わせ目の中央（下唇側） | 鼻の穴の外側の端（小鼻側） |
| あご先（下あごの先端） | 小鼻の外側（小鼻のふくらみの一番外） |
| あごの下（あごと首の境目の中央） | ほうれい線の上端（小鼻の付け根の横） |
| | 口角 |
| | こめかみ（目の高さでのマスクの横の端） |
| | エラの角（あごの角） |
| | エラの下（あご下と首の境目） |
| | おでこの上の端（マスク上端の角） |

頭全体（Coverage: **Whole Head**、初期値）では、さらに次の点を打ちます。

| 中心線 | 片側 |
|---|---|
| 頭頂（頭の一番高い所） | 耳の付け根の上端 |
| 後頭部（頭の一番後ろに出た所） | 耳の付け根の下端（耳たぶの付け根） |
| うなじ（後頭部と首の境目の中央） | 首の横の下端 |
| 首の後ろの下端（作る範囲の下端） | |
| 首の前の下端（のどの下・作る範囲の下端） | |

コツ:
- 鼻の穴の点は、下から見上げるようにビューを回して打つと正確です。
- 「あごの下」「エラの下」は、下から見上げてあごの裏側に打ちます。
- 唇の点は、上下の唇が接する線（口の切れ目）の上に打ちます。

トポロジー:
- 目と口の周りに同心ループがあり、口は上唇と下唇でループの数を揃えています。
- 鼻の穴は、縁のループと小鼻のループの二重のリングで囲まれ、鼻柱・上唇・ほうれい線へ流れます。
- 鼻すじ、目頭の横、額、目の下、頬の5か所に、極（5本の辺が集まる頂点）を1つずつ置いています。
- 中心線上の頂点は、すべて4本の辺になるようにしています。
- あごの下は、首との境目まで作ります。
- 頭全体では、顔のループがそのまま頭を一周するように流れます（お手本の画像と同じ構成）。おでこ・こめかみ・あごの外側で一段だけ面を割って、後頭部と首を顔と同じくらいの密度にしています。
- 耳は作らず、**耳の付け根に2重のループの台座（穴）**を作ります。耳は別に作ってつなぐか、Quad Draw で穴を埋めてください。
- 首の下端は、指定した高さで開いたまま終わります。

設定:
- **Symmetric**: 中心線の点と、スキャン自体の左右対称性から鏡面を求めます。頭が少し傾いていても大丈夫です。片側のガイドはミラーされます。左右で形が大きく違うスキャンでは OFF にして、両側（計34点）を打ってください。
- **Coverage**: Face Mask（顔だけ）／ Whole Head（頭全体と首、初期値）
- **Density**: 顔だけ 1/2/3 = 約780 / 2000 / 3900 頂点、頭全体 = 約1300 / 3300（初期値）/ 6200 頂点

## 手のガイド（21 点・すべて手の甲側）

1. 手首（手の甲側の中央）
2. 親指 → 人差し指 → 中指 → 薬指 → 小指 の順に、各指 4 点
   - 付け根の関節（ナックル）→ 第2関節 → 第1関節 → 指先
   - 親指は「付け根（手首寄りの膨らみ）→ 付け根の関節 → 関節 → 指先」

- **Finger Edges**: 指1本の周りの分割数。16 / 12（初期値・約1600頂点）/ 8
- **Finger Loop Density**: 指の輪切りの密度。1 で正方形に近い面、2 で倍の本数
- **Knuckle Loops**: 各関節（ナックル・第2関節・第1関節、親指の関節）の甲側に楕円のループを入れる
- 親指は、手のひら側の付け根のふくらみ（母指球）から生えます。広い付け根から 3→1 の四角形の絞り込みで指の太さにつなぎます。
- **Forearm Loops**: 手首より先の前腕に伸ばすループ数（スキャンに前腕がある範囲だけ作られる）

指を曲げたポーズでも、関節の位置に沿ってチューブが曲がります。頂点は骨の中心から外向きにレイを飛ばして置くので、指同士がくっついていても隣の指に吸着しにくい作りです。

## 仕組み

- **顔**: 理想的な顔トポロジーを「四角形パッチのレイアウト」としてコードで設計し、そこから型を生成します。ガイド点で位置合わせ（相似変換）と RBF 変形を行い、型の相対形状を保ったまま表面への吸着と緩和を繰り返します。
- **手**: ガイドから骨格（各関節の骨の中心と太さ）を推定し、その周りに輪を作って表面に投影します。

## 制限

- 全身にはまだ対応していません（頭部と手のみ）。
- 動作確認は、実在の頭部スキャン（Lee Perry-Smith、three.js のサンプル）、手のモデル（WebXR の汎用ハンド）、合成モデルで行っています。
- 鼻の穴の奥・目頭・耳の付け根まわりなど、凹みの深い所では面が少し裏返ることがあります（実スキャンで全体の約4%）。気になる所は Quad Draw で整えてください。
